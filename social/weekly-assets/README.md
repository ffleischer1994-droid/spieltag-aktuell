# Original-Cover für automatische Instagram-Karussells

Hier die beiden freigegebenen Originaldateien aus dem Chat hochladen:

- `free-tv-cover.png` — Titel der Free-TV-Wochenvorschau
- `weekend-cover.png` — Titel der Wochenend-Highlights

Die Bilder müssen jeweils 1080 × 1350 Pixel groß sein. Das feste Datum in der Datums-Pille wird beim Rendern mit dem jeweiligen Datumsbereich überdeckt und dynamisch neu geschrieben.

Die GitHub Action stoppt absichtlich ohne Veröffentlichung, solange das passende Cover fehlt. Dadurch werden keine Ersatzmotive veröffentlicht.

Zeitplan (Europe/Berlin): Montag 17:00 Free-TV und Freitag 15:00 Wochenende. Die täglichen Beiträge bleiben getrennt.
